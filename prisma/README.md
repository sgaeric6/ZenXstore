# Prisma Database

This folder contains the Prisma ORM configuration and database schema.

## Features

- Database schema
- User model
- Free Fire account model
- Orders model
- Transactions model
- Refund requests
- Support tickets
- Admin roles

## Database

- PostgreSQL
- Prisma ORM

## Commands

```bash
npx prisma generate
npx prisma migrate dev
npx prisma studio
```

## Tables

- Users
- FreeFireAccounts
- Orders
- Transactions
- RefundRequests
- SupportTickets
- Admins
